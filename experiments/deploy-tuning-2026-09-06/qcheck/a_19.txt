HTTP **401** 和 **403** 都表示“请求被拒绝”，但原因不同：

## 1. HTTP 401 Unauthorized：未认证

**401** 表示客户端**没有提供有效身份认证信息**，或者认证失败。

简单说：

> 服务器不知道你是谁，或者你提供的身份凭证无效。

### 常见场景

- 没有登录就访问需要登录的接口
- Token 过期
- Token 无效
- 用户名或密码错误
- 没有携带 `Authorization` 请求头

### 示例

```http
GET /api/profile HTTP/1.1
Host: example.com
```

服务器返回：

```http
HTTP/1.1 401 Unauthorized
WWW-Authenticate: Bearer
```

### 客户端通常怎么做？

客户端可以重新登录、刷新 Token，然后再次请求。

---

## 2. HTTP 403 Forbidden：无权限

**403** 表示服务器已经知道你是谁，但你**没有权限访问这个资源**。

简单说：

> 服务器知道你是谁，但不允许你访问。

### 常见场景

- 普通用户访问管理员接口
- 用户没有某个资源的访问权限
- 账号被禁用
- IP 被限制
- 角色权限不足

### 示例

```http
GET /api/admin/users HTTP/1.1
Host: example.com
Authorization: Bearer valid-token
```

服务器返回：

```http
HTTP/1.1 403 Forbidden
```

### 客户端通常怎么做？

重新登录通常也没用，因为问题不是“你是谁”，而是“你没有权限”。

---

## 核心区别

| 状态码 | 含义 | 是否知道用户身份 | 是否可以通过重新认证解决 |
|---|---|---|---|
| 401 | 未认证 | 不知道或认证失败 | 可以，重新登录或刷新 Token |
| 403 | 无权限 | 通常已经知道用户身份 | 通常不可以，需要更高权限 |

---

## 一句话总结

**401 是“你没登录或登录无效”，403 是“你登录了，但没权限”。**
