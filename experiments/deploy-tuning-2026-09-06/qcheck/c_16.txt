KV cache 用于在自回归解码时缓存已生成 token 的 Key 和 Value。

在 Transformer 解码中，每生成一个新 token，都需要用它的 Query 去和之前所有 token 的 Key/Value 做注意力计算。如果没有 KV cache，每生成一个 token 都要把整个历史序列重新前向计算一遍，重复计算大量 K/V。

使用 KV cache 后：

- 历史 token 的 K/V 已经算好并缓存；
- 每步只需计算新 token 的 K/V；
- 新 K/V 追加到缓存中；
- 注意力只基于缓存的 K/V 计算。

因此能显著减少重复计算，降低每步解码的计算量，从而加速生成。代价是 KV cache 会占用较多显存，且随序列长度、层数、注意力头数增长。
