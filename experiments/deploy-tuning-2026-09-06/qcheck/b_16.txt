KV cache 在自回归解码中的作用是：**缓存已经生成 token 的 Key 和 Value**，避免每生成一个新 token 时都重新计算历史 token 的 K/V。

在 Transformer 解码时，第 \(t\) 步生成新 token 需要计算：

\[
\text{Attention}(Q_t, K_{1:t}, V_{1:t})
\]

如果没有 KV cache，每步都要把前面所有 token 重新过一遍模型，重新算出 \(K_{1:t}\) 和 \(V_{1:t}\)。  
有了 KV cache，则只需：

1. 计算当前新 token 的 \(Q_t, K_t, V_t\)；
2. 把 \(K_t, V_t\) 追加到缓存中；
3. 用 \(Q_t\) 和缓存中的历史 \(K, V\) 做注意力。

它能加速的原因是：**避免了大量重复计算**。  
每步只需要处理新增的一个 token，而不是重新处理整个前缀，从而显著减少计算量，尤其在生成长序列时效果明显。

代价是：KV cache 会占用额外显存，因为需要保存历史 token 的 K/V。
