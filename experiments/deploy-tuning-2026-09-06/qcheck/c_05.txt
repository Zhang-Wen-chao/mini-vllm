在 Transformer 中，**LayerNorm（层归一化）** 通常作用在单个 token 的特征维度上，即对每个样本/时间步的隐藏向量做归一化：

\[
\text{LayerNorm}(x)=\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}\gamma+\beta
\]

其中 \(\mu, \sigma^2\) 是在特征维度上计算的均值和方差，\(\gamma, \beta\) 是可学习参数。

## LayerNorm 的作用

1. **稳定激活分布**  
   将每层输出的数值范围拉回较稳定的区间，避免激活值过大或过小。

2. **改善训练稳定性**  
   减少梯度爆炸、梯度消失的风险，使训练过程更平滑。

3. **允许使用更大学习率**  
   归一化后参数更新更稳定，通常可以比没有 LayerNorm 时使用更大的学习率。

4. **缓解内部协变量偏移**  
   虽然 Transformer 中更常从“稳定训练”角度理解，但 LayerNorm 也能让每层输入分布更一致。

5. **提升深层网络可训练性**  
   对深层 Transformer 尤其重要，有助于残差连接和梯度传播。

# Post-LN 和 Pre-LN 的区别

Transformer 中每个子层通常包含一个非线性变换，例如 Self-Attention 或 FFN，并配合残差连接。

## 1. Post-LN

原始 Transformer 使用的是 **Post-LN**，即先做子层变换和残差相加，再做 LayerNorm：

\[
x_{\text{out}} = \text{LayerNorm}(x + \text{Sublayer}(x))
\]

例如：

\[
x = \text{LayerNorm}(x + \text{Attention}(x))
\]

\[
x = \text{LayerNorm}(x + \text{FFN}(x))
\]

### 特点

- 是原始 Transformer 的结构。
- 归一化作用在残差相加之后。
- 残差流中的数值可能随层数增加而变大。
- 深层网络训练时可能不够稳定。
- 通常需要学习率 warmup、较精细的初始化。
- 在较浅模型上效果很好，但深层模型训练难度更高。

---

## 2. Pre-LN

**Pre-LN** 是先对输入做 LayerNorm，再进入子层，然后做残差相加：

\[
x_{\text{out}} = x + \text{Sublayer}(\text{LayerNorm}(x))
\]

例如：

\[
x = x + \text{Attention}(\text{LayerNorm}(x))
\]

\[
x = x + \text{FFN}(\text{LayerNorm}(x))
\]

### 特点

- 归一化作用在子层输入之前。
- 残差连接路径更“干净”，梯度更容易传播。
- 训练更稳定，尤其适合深层 Transformer。
- 通常对学习率 warmup 的依赖更小。
- 初始化更简单，训练更容易收敛。
- 有时需要在最终输出前再加一个 LayerNorm，例如：

\[
\text{output} = \text{LayerNorm}(x)
\]

然后再接分类头或语言模型头。

---

# 核心区别总结

| 对比项 | Post-LN | Pre-LN |
|---|---|---|
| 公式 | \(\text{LN}(x + \text{Sublayer}(x))\) | \(x + \text{Sublayer}(\text{LN}(x))\) |
| 归一化位置 | 残差相加之后 | 子层输入之前 |
| 原始 Transformer | 是 | 否 |
| 训练稳定性 | 相对较差，尤其深层 | 更好 |
| 梯度传播 | 可能受残差流数值变化影响 | 更稳定 |
| 学习率 warmup | 通常需要 | 通常可减弱或不需要 |
| 深层模型 | 更难训练 | 更适合深层 |
| 最终输出 | 通常已有 LN | 常需额外加一个 LN |

---

# 直观理解

可以把 Transformer 的残差连接理解为：

\[
x \leftarrow x + f(x)
\]

其中 \(f(x)\) 是 Attention 或 FFN。

- **Post-LN**：  
  先让 \(x + f(x)\) 相加，再归一化。  
  如果 \(x\) 本身随着层数增加变得很大，归一化虽然能压回来，但训练过程中数值波动可能较大。

- **Pre-LN**：  
  先归一化 \(x\)，再计算 \(f(\text{LN}(x))\)，最后加回原始 \(x\)。  
  这样进入 Attention/FFN 的输入更稳定，残差主路径也更稳定。

---

# 简单结论

**LayerNorm 的核心作用是稳定 Transformer 的训练过程。**

**Post-LN** 是原始 Transformer 的做法，归一化在残差之后，结构经典但深层训练较难；  
**Pre-LN** 是更现代、更稳定的做法，归一化在子层之前，残差路径更干净，训练更容易，尤其适合深层 Transformer。
